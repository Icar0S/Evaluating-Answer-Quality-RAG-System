Problema → Abordagem → Sistema → Resultado

01

Problema

Sistemas RAG podem soar confiantes mesmo quando alucinam. Avaliar a qualidade de resposta de forma consistente, reprodutível e sem depender só de julgamento humano manual é um problema aberto — especialmente com modelos 100% locais.

02

Abordagem

Construir o assistente RAG e sua bateria de testes lado a lado: pipeline manual e instrumentado (sem caixas-pretas de orquestração), logging estruturado de toda interação, e avaliação semântica via LLM-as-a-Judge com revisão humana como contraponto.

03

Sistema

Ollama (geração + embeddings 100% locais) → ChromaDB (índice vetorial) → FastAPI (API instrumentada, métricas de recursos em tempo real) → frontend próprio para testes de API e E2E isolados.

04

Resultado

Um assistente que recusa graciosamente perguntas fora do contexto em vez de alucinar, com métricas de fidelidade/relevância via RAGAS e cobertura E2E via Playwright — base experimental para o artigo. (Fase 2 em andamento.)
